## About the Project 
This group project uses intertidal monitoring data collected through OPIHI (Our Project in Hawai'i's Intertidal) to better understand ecological trends and improve data organization 

## Research Question
*How does the occurrence of native and non-native intertidal species vary across sites and over time in Hawaiʻi?*

## Project Objectives 
- Clean and organize OPIHI monitoring data
- Develop a reproducible data-processing workflow using R
- Create a master dataset and accompanying data dictionary
- Develop a reusable R function for future monitoring data

## Group Topic  
For a selected taxon or group, where and when was it recorded? Make an occurrence or detection-frequency summary, explicitly distinguishing absence from not surveyed and accounting for sampling effort.
