1 1st Script: Cleaning Up Raw Data

1.1 Project question

Question C, Species occurrence: for selected taxa, where and when were they recorded across OPIHI surveys, and how often were they detected once sampling effort (number of quadrats) is accounted for?

Primary metric (to be finalised): detection frequency = quadrats where the taxon was recorded / quadrats sampled, per site-visit, summarised by site and year.

1.4 2. Cleaning decisions log

Decisions agreed by the team, applied by code (never by hand-editing raw files).

# Issue Decision
1 Rows labelled “EXAMPLE” (student templates) Remove; log in exclusions
2 Metadata date differs from data-row date (e.g. Mauliola 2026: 4/26 vs 4/20) Data-row date wins; metadata date likely the sheet creation date
3 Times like 01:14 for a field trip Times standardised to 24-h HH:MM. Hours 01–05 assumed PM (+12 h) and flagged
4 #REF! and other spreadsheet errors Set to NA

7 Classroom group-total files Kept with resolution = "group_total"; excluded from detection frequency
8 Transect point-intercept data Not in the master (quadrat data only); possible secondary table
9 Blank cells Blank cell in a filled quadrat = 0 (not detected); entirely blank row = missing
10 Legacy block with no date/site/school (2020 file, block 8) Excluded; logged
11 Legacy quadrat column with data but blank header Kept; transect/quadrat inferred from neighbours; flagged inferred
12 Teacher IDs Legacy: School is the teacher stand-in. Modern: Team Leader. One anonymised ID per survey (site + date); several leaders → IDs sorted and joined with ;. Names split on , / and / &, trimmed, case-fixed first
13 Student names (“Data Entry By”) Not in the public master (not needed for Question C; protects students)
14 Modern rows with no date and all taxa blank/0 Leftover template rows; excluded as blank_template_row
15 Modern rows with date/site but no taxon entries Quadrat not entered; excluded as no_taxon_data, not counted as effort

1.8 6. Site and taxon harmonisation

Names are standardised with two editable lookup tables in Data/Lookups/. Each raw spelling is reduced to a key (lower case, extra spaces removed; for sites also ʻokina, apostrophes and kahakō removed), and the key is looked up in the table. To fix or add a name, edit the CSV, not the code.

  • site_crosswalk.csv: raw site key → site_name (Hawaiian name first, no ʻokina/kahakō), site_alias_english, island.
  • taxon_crosswalk.csv: raw taxon key → taxon_clean (spelling fixed, current name), analysis_taxon (usually genus, matching OPIHI’s ID resolution), category (Algae, Cyanobacteria, Invertebrate, Coral, Substrate, Unknown, Invalid). Lines marked REVIEW are judgement calls worth checking.

Any name not in a lookup is listed with the closest existing key as a suggestion (edit distance); it is never matched automatically.

1.8.1 Reusable function: checking taxon names in new data

standardize_taxa() (in Scripts/clean_build.R) checks taxon names against the team’s lookup table, Data/Lookups/taxon_crosswalk.csv. 5 5th Script: Summary Table

5.1 Purpose

This document builds the project’s “beautiful tidy table” (assignment step 2: “Visualize a subset of the data in a beautiful tidy table”) for our question:

How do the occurrence (distribution) and abundance of invasive and native algae compare across OPIHI intertidal surveys, 2004–2026, accounting for sampling effort?

It reads only the cleaned, de-identified outputs in Data/Processed/ (the _completed versions, which add the team’s post-cleaning corrections listed in opihi_change_log.csv) and the team’s algae origin lookup in Data/Algae/. It does not touch the raw data. The table is saved to Outputs/ as a PNG (for slides and the README) and as HTML, along with a CSV of every algal taxon.

5.2 Design choices

Choice Why Assignment link
Metric = % of quadrats where a taxon was recorded, with the number of quadrats and sites shown in each column header Detection frequency divides by effort (quadrats sampled), so sites and years sampled more heavily don’t look “richer” just because of effort Question C: “detection-frequency summary, accounting for sampling effort”
Distribution = number of sites and islands where each taxon was recorded Answers where, alongside when (the period columns) Question C: “where and when was it recorded?”
Abundance = mean % cover where present (points hit ÷ 25) Separates how common a taxon is from how much space it takes up once it is there Our question compares abundance as well as distribution
Three sampling periods (2004–2008, 2016–2020, 2024–2026) OPIHI data fall in these three blocks; there are no surveys 2009–2015 or 2021–2023 at quadrat level Shows change over time without implying a continuous trend
Origin status from the team’s algae_origin_review.csv / algae_origin_lookup.csv One shared classification for the table and both figures; anything a teammate fills into your_status overrides the default Documented decisions; consistency across the report
Only species-level IDs are classed native or invasive; genus-only records, uncertain-origin species and functional groups are summarised separately Genera such as Hypnea and Gracilaria contain both native and invasive species, so genus-level records can’t honestly be assigned Taxonomic care; “don’t draw broad conclusions”
Quadrat-level records only (classroom group totals and cyanobacteria excluded, stated in the table note) Group totals cannot give per-quadrat detection; cyanobacteria are not algae Explained exclusions
8 most widespread native taxa shown; all taxa written to CSV Keeps the table readable while losing nothing Tidy subset of the data
No teacher IDs or names; no statistics Table uses only site, island, year and taxon; the summary is exploratory Data stewardship; “statistics are not expected”

5.5 Summary for every algal taxon

summarise_occurrence() turns detection records into one row per group with detection frequency by period (effort-corrected), distribution and mean cover. It is used twice: once per taxon and once per origin status.

Show R Code 
# Inputs : det    - one row per sample x group: sample_id, group columns, points
#          effort - every quadrat sampled: sample_id, period, site_name, island
#          ...    - the grouping columns
# Output : one row per group: % of quadrats recorded in each period and overall,
#          sites, islands, mean % cover where present, quadrats recorded
summarise_occurrence <- function(det, effort, ...) {
  grp <- names(select(det, ...))          # grouping column names, for the final join
  det <- det |>
    mutate(cover = pmin(points, 25) / 25) |>
    left_join(select(effort, sample_id, period, site_name, island), by = "sample_id")
  per_period <- det |>
    count(..., period, name = "n_det") |>
    left_join(count(effort, period, name = "n_quadrats"), by = "period") |>
    mutate(pct = 100 * n_det / n_quadrats) |>
    select(..., period, pct) |>
    pivot_wider(names_from = period, values_from = pct, values_fill = 0, names_expand = TRUE)
  det |>
    group_by(...) |>
    summarise(quadrats_recorded = n_distinct(sample_id),
              pct_all = 100 * quadrats_recorded / nrow(effort),
              sites   = n_distinct(site_name),
              islands = n_distinct(island),
              cover   = 100 * mean(cover),
              .groups = "drop") |>
    left_join(per_period, by = grp)
}

5.8 Reading the table (exploratory)

  • Invasive species were recorded in 15.2% of quadrats, compared with 22.3% for native species. They were found at 24 of 42 sites on 6 islands.
  • Acanthophora spicifera is the most widespread invasive (9.7% of quadrats, 22 sites).
  • 56.2% of quadrats contain algae identified only to genus, so a large part of the algal record cannot be assigned an origin.

All period-to-period differences are confounded by which sites were sampled (see table note a). No statistical tests were run.
